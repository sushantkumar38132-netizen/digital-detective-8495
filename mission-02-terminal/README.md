### Task 2.2 — Safe File Handling Questions

1. **What is the difference between replacing a file's contents and adding text to the end?**
   - **Replacing (`>`):** Overwrites the file completely. Any pre existing data is wiped out and replaced with the new output.
   - **Adding to the end (`>>`):** Appends new data to the end of the file, keeping all existing contents completely intact.

2. **What is the difference between copying a file and moving a file?**
   - **Copying (`cp`):** Creates an independent duplicate of the file in another location or with a new name the original file remains unchanged.
   - **Moving (`mv`):** Changes the file's path or name in the file system table without creating a duplicate the file ceases to exist under its old name and location.

3. **What information does the current-directory display (`pwd`) provide?**
   - It provides the full absolute path starting from the root directory (`/`) to about where commands and relative paths will execute.

4. **Why is a directory-listing operation (`ls`) useful?**
   - It gives immediate confirmation of which files and folders exist, verifies that file creation or move operations succeeded and displays file detailes (sizes, permissions).

### Task 2.3 — Flags and Pipes

#### 1. Comparing Normal vs Modified Directory Listings
- Running `ls` only prints non hidden file names in columns.
- Running `ls -lhA`:
  - `-l`: Formats output into a detailed list (permissions, links, user, group, size, date).
  - `-h`: Formats file sizes into human readable units (`K`, `M`, `G`) instead of raw byte counts.
  - `-A`: Displays almost all files, including hidden dotfiles (e.g., `.git`, `.gitignore`), omitting only `.` and `..`.

#### 2. Pipeline Execution (`ls -la | head -n 5`)
- **What the pipe (`|`) symbol does:** The pipe takes the standard output (`stdout`) generated by the program on the left and channels it as standard input (`stdin`) to the program on the right, without writing intermediate data to disk.
- **Left-hand side (`ls -la`):** Generates a comprehensive detailed stream of all directory contents and metadata.
- **Right-hand side (`head -n 5`):** Reads the incoming stream, filters it and outputs only the first 5 lines to the terminal screen.

#### Why Package Managers are Useful:
A package manager automates the entire software installation, configuration, updates, and removal from the command line. Instead of manually downloading installers, extracting, and configuring environment paths, the package manager resolves and fetches all required software dependencies automatically, ensuring system compatibility and easy security upgrades.
